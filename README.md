# PFG Pathfinder

A **compass for Star Citizen ground vehicles**. Press Pause in game and Pathfinder pings your position; the arrow shows which way to steer for your next waypoint. Built for Team ODB's Daymar Rally practice.

**Full guide with pictures: [pathfinder.peacefroggaming.com](https://pathfinder.peacefroggaming.com)**

## Download

**[⬇ Download PFG-Pathfinder-portable.exe](https://github.com/PeaceFrog71/pathfinder-releases/releases/latest/download/PFG-Pathfinder-portable.exe)**: always the newest build. The version shows next to the panel title; [release notes](https://github.com/PeaceFrog71/pathfinder-releases/releases/latest).

- Windows 10 / 11, 64-bit. One file, no install: run it and it starts.
- Unsigned: Windows SmartScreen warns once. Click **More info → Run anyway**.
- **Star Citizen in Borderless Windowed mode** (Settings → Graphics → Window Mode), with the **chat panel visible** (F12 toggles it).

## Keys

| Keys | What it does |
|---|---|
| `Pause` | Ping: types `/showlocation` into chat for you and hands control back. Only while Star Citizen is the active window. |
| `Ctrl+Alt+P` | Switch between interactive (click, move, resize) and click-through (the game gets every click). |
| `Ctrl+Alt+Shift+P` | Quit. |

## Training only

ATMO rule 11.1 disqualifies a team for using unauthorized third-party software during a race. Use Pathfinder for practice and route learning, and close it on race day; your support ship calls the turns instead.
